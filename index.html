Sobre mí

Soy Martín Acevedo, desarrollador fullstack y estudiante de desarrollo web en Skillnest. Me gusta transformar ideas en aplicaciones claras, ordenadas y agradables de usar. Aprendo construyendo soluciones completas: cada proyecto es una oportunidad para entender mejor el frontend, el backend y cómo se conectan.

Busco una oportunidad laboral o de práctica profesional como desarrollador fullstack, donde pueda aportar con entusiasmo, aprender de un equipo y seguir creciendo en la creación de aplicaciones web completas.

Perfil

Desarrollador fullstack, con conocimientos de HTML semántico, CSS moderno, JavaScript, Python y Flask.

Intereses

Desarrollo de aplicaciones web, experiencia de usuario, accesibilidad y APIs.

Aprendiendo

Creacion de rutas con flask, creación de APIs y creacion de bases de datos funcionales.

Mi camino de aprendizaje

Etapa 1

HTML y CSS

Aprendí a estructurar páginas y a darles estilo: maquetación, colores, tipografías y diseño responsivo.

Etapa 2

JavaScript y DOM

Empecé a darle vida a mis páginas con eventos, funciones y manipulación de elementos.

Etapa 3

Python

Lógica de programación, estructuras de datos y desarrollo con scripts y resolución de problemas.

Etapa 4

Git y GitHub

Control de versiones, repositorios y publicación de mis proyectos en GitHub Pages.

Etapa 5

Flask

Desarrollo web del lado del servidor, creación de rutas, APIs y conexión de lógica.
